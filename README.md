# Restaurant Homepage


A responsive restaurant homepage UI design built with HTML & CSS.

### Features
- Fully responsive layout for mobile & tablet
- Hero section with background image
- Menu section layout design
- Clean and modern UI

### Note
This is a static frontend design. Menu buttons and links are for UI demonstration only and are not functional.

### Tech Stack
- HTML5
- CSS3
